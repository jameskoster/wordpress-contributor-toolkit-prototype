# WordPress Contributor Toolkit prototype

Design prototype for a redesign of the [WordPress Contributor Toolkit](https://github.com/WordPress/contributor-toolkit), the official desktop app for setting up a WordPress Core or Gutenberg development environment.

This is not the official app. It explores the interface: local sites, Core and Gutenberg checkouts, tickets and pull requests, and the workflows around them. Nothing here talks to a real development environment.

Preview: https://wp-contributor-toolkit.view.fast/

## Run locally

```bash
npm install
npm run dev
```

The dev server starts at http://127.0.0.1:5173.
